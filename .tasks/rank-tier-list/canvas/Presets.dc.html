About the four pictured presets These are the real files, fetched from the addresses the presets ship and embedded in this canvas — the same bytes Obsidian will load. The art is generated from each card's own name, so it is a stable distinct mark per card, never a photograph of that dish or that game: a generator cannot draw ramen.
