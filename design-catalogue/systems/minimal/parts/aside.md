# Aside

A column on the right that explains or supports the page; it never navigates the product. Ref 12 (right) and ref 13.

## Page aside

For a long page: an article, a guide, a prompt pack.

```
 ┌──────────────────────┐
 │ Steps                │   ← one plate holds the page's own tools
 │ 01 Lock taste        │
 │ 02 Unslop            │
 │ 03 Polish            │
 │ ──────────           │
 │ Share                │
 │ Copy link · X        │
 │ ──────────           │
 │ All prompts          │
 └──────────────────────┘
   Sponsored              ← below the plate, on the page: quieter things
   ▣ Framer   one line
   ▣ CleanShot one line
```

- One plate groups the page's own tools: its contents, share, a way back. Lines divide them inside the plate.
- Things that are not about this page (related links, sponsors) stand below the plate with no plate of their own.
- Width 280–320px. Sticks to the top while the page scrolls.

## Record aside

For a record page: facts, the next step, related records (refs 5 and 7).

- Each question gets its own card: Details, Next step, Related.
- Facts are label–value rows: the label in ink-2 on the left, the value on the right.
- Width 320px. Below the `lg` width it moves under the page header.

## Rules

- An aside never repeats the sidebar's navigation.
- It holds at most three groups; a fourth belongs on the page.
- On a narrow window it moves below the page's content, or into a sheet opened from the header.
