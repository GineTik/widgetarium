# Command-first

One input leads the page; what it produced stands below it. Navigation is quiet or hidden.

```
┌──────────────────────────────────────────────┐
│ mark  Assistant  Portfolio  Today      ●     │
│                                              │
│          The display question                │
│        ┌──────────────────────────┐          │
│        │ Describe what you need…  │          │
│        └──────────────────────────┘          │
│        suggestion · suggestion               │
│        history                               │
└──────────────────────────────────────────────┘
```

| Part     | Holds                                                                                      | Size                                  |
| -------- | ------------------------------------------------------------------------------------------ | ------------------------------------- |
| top line | mark, 3–6 sections as words, the account                                                   | 48–56px, quiet                        |
| input    | the one input, its attachments and send                                                    | 560–720px column                      |
| below    | 2–4 suggestions, then the history as plain rows                                            | the same column                       |
| answer   | once asked, the page turns into the conversation with results inline (tables, maps, cards) | the same column, widening for a table |

- The input is the only filled block on the empty page.
- Results open as rich blocks inside the conversation, not as new pages; a block may open its full view as L3.

**Folding:** the top line folds into one `menu`; the column takes the full width.

**Fits:** AI assistants, search-led tools, research tools. **Not for:** apps whose daily work is lists and records (use the sidebar or rail and list, with the assistant as one section).
