# Top bar

L1 as words across the top; the page takes the whole width under it.

```
┌──────────────────────────────────────────────────────────┐
│ mark  Home  Leads 9  Deals  Reports   search ⌘K  bell  New ● │
├──────────────────────────────────────────────┬───────────┤
│ page header                                  │ L3        │
│ page, full width                             │ (opens on │
│                                              │  demand)  │
└──────────────────────────────────────────────┴───────────┘
```

| Part    | Holds                                                                                                       | Size              |
| ------- | ----------------------------------------------------------------------------------------------------------- | ----------------- |
| top bar | mark and product name; up to 8 sections as words with counts; search, notifications, one `New`, the account | 56–60px tall      |
| page    | the page header, then the base                                                                              | full width        |
| L3      | the record opened from the page                                                                             | 400–480px `sheet` |

- The selected section is the word in full ink with the design system's selected mark under it.
- No second row of navigation: sections that need sub-sections become tabs in the page header.

**Folding:** below the width the words need, they fold into one `menu` button; the product name hides before the search does.

**Fits:** up to 8 flat sections, pages dominated by wide tables. **Not for:** nested sections (use the sidebar), apps lived in all day through a list (use rail and list).
