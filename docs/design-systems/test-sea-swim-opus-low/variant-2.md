# Variant 2 — Tide table

Fit profile and dropped traits: see `variant-1.md`.

## Idea

The journal is printed in one sea ink like a tide table: every number, photo and line is a tone of the same deep water, and nothing is lifted off the page but one sheet.

| Category   | Trait                                                   | Why                                           |
| ---------- | ------------------------------------------------------- | --------------------------------------------- |
| Colour     | V-C1 one hue family for the whole UI                    | the ink idea                                  |
| Colour     | V-C2 tonal steps with jobs                              | steps give hierarchy without a second hue     |
| Colour     | V-C3 no pure grey; photos too are toned                 | user photos printed duotone in the ink        |
| Functional | V-F1 instruments from ticks and stripes                 | tide-table marks: tick rows, striped progress |
| Type       | G-T1 neo-grotesk, medium titles and figures             | tabular, printed feel                         |
| Surfaces   | G-S2 facts as outline chips, no fill                    | a printed page has rules, not plates          |
| Layout     | G-L1 strict padding, images never bleed                 | a table page has margins                      |
| Imagery    | G-M1 photos are user content                            | the only photos are the swimmer's             |
| Surfaces   | K-S1 two plates only (here: one sheet)                  | the page is ink on pastel                     |
| Surfaces   | K-S3 one sheet holds the whole list                     | the journal is one table, not cards           |
| Functional | K-F1 hairline charts, one value solid with its pill     | the season curve as a tide line               |
| Controls   | K-K3 one full-width pill only where an action completes | "Log swim" is the only strong button          |

Sources: Verdant 4 · Gallery 4 · Cloud 4 (12). Conflict avoided: G-C3 black-only and K-C1 neutral UI dropped against V-C1.

## Colour

Logic V-C2, hue deep petrol (H ≈ 215).

## Imagery

Role: user content only (G-M1). Kept in line by printing every user photo duotone deep → pastel (V-C3). Design photos: none. Queries: `rocky coast waves`, `swimmer open water`.

## Signature components

- **Tide row** — today's hours as a tick row; swim window as stripes.
- **Go / no-go line** — conditions as outline chips; the verdict as the single signal mark.
- **Season tide line** — hairline curve of swims per week, this week solid with a pill.
- **Journal table** — one sheet, a duotone thumb per row, tabular figures.

## The design book must

Read as one printed sheet in one ink: no full-colour photo, no card per item, figures in tabular columns.
